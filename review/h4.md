## Open

- **The duplicate test reads the whole log on every call.** 388 rows; if the log ever reaches tens of thousands of rows this is a `read` per backtest and would want an index. Not a problem at this size.
- **A rerun at the same commit with the same note** (a `run-all` twice in one session) is now silent: the second call returns the first row and nothing says so at the CLI. `summary_line` prints the run's own numbers either way, which are the same numbers.

## Against the plan

- **"Set the column from the code, not the note."** The column already held the code's answer, so no cell changed; the plan's instruction is read as "establish it from the code", which this file does. Editing rows the file already has right would have been an edit to an append-only log.
- **"Results table column order: DSR (all) before DSR (cand.)"** was already the case (G2 wrote the header that way); only the prose and the header sentence needed the change.
- **Return value.** `log_specification` returned None; it now returns the row (new or existing), which the test uses. `portfolio.log_specification` re-exports the same function.
